# FunPay Helper

Первая версия расширения для Chrome и Edge. Тёмный интерфейс, шаблоны ответов и личные заметки о покупателях. Manifest V3, без сервера, npm-зависимостей и подключения к аккаунту через токены.

## Установка

1. Скачайте [funpay-helper-0.1.0.zip из релиза](https://github.com/Bezsmertny/Funpay-Helper/releases/download/v0.1.0/funpay-helper-0.1.0.zip) и распакуйте в отдельную папку. В ней должен находиться `manifest.json`. При локальной сборке архив находится в `dist/`.
2. Откройте `chrome://extensions` (Chrome) или `edge://extensions` (Edge).
3. Включите **Режим разработчика → Загрузить распакованное расширение** и выберите эту папку. При установке из исходников выберите `extension/`.
4. Обновите открытую страницу `https://funpay.com/`. Справа внизу появится кнопка **Helper**.
5. Закрепите значок расширения на панели браузера. По нажатию открываются настройки темы, анимаций, шаблонов и список отмеченных покупателей.

Папку расширения нужно сохранить на компьютере. После обновления исходников нажмите «Обновить» на странице расширений и перезагрузите FunPay. В магазине расширений эта версия не опубликована.

## Возможности

| Функция | Как использовать |
| --- | --- |
| Тёмная тема | Включается в настройках; применяется к странице FunPay без перезагрузки. |
| Анимации | Плавное появление панели и переходы элементов. Учитывается системная настройка уменьшения движения. |
| Метки покупателей | Откройте чат или профиль → Helper → «Метка покупателя». Выберите категорию, добавьте свою подпись (до 24 символов) и заметку (до 500 символов). |
| Выбор покупателя | «Выбрать по ссылке на профиль» → нажмите имя на странице. Метки привязаны к числовому ID, а не к изменяемому нику. |
| Локальный игнор | Скрывает сообщения с явно определённым автором; можно показать их обратно. Метка игнора появляется возле ссылок на профиль. |
| Быстрый ответ | «Ответ покупателю» вставляет шаблон в пустое поле открытого чата. Отправляете вы. `{buyer}` заменяется именем покупателя. |
| Автоответ в чате | Включите флажок в Helper для открытого чата и подтвердите отправку. Работает только с новыми сообщениями его покупателя и только в видимой вкладке. |
| Ответы на отзывы | Откройте форму ответа на отзыв → «Ответы на отзывы». Можно включить автоматическую подстановку при появлении формы. Перед публикацией проверьте текст и нажмите кнопку FunPay. |
| Перевод | Выделите текст или откройте лот → «Перевести описание / выделение». Откроется Google Translate с выбранным языком. До 4500 символов за раз. |
| Список покупателей | В настройках можно искать по имени, ID, подписи и заметке; переходить в профиль или удалять запись вместе с игнором. |

## Границы первой версии

- **Игнор локальный.** Он не запрещает покупателю писать и не меняет чёрный список аккаунта FunPay. Серверная блокировка не реализована.
- **Ответы на отзывы не публикуются автоматически.** Автоподстановка шаблона и ручная публикация реализованы; полная автоотправка отзывов пока отсутствует.
- Перевод открывается в отдельной вкладке Google Translate. Перевод прямо внутри лота пока отсутствует. Текст передаётся Google только по вашему нажатию.
- Автоответ отключается при перезагрузке или смене чата. Он пропускает сообщения в скрытой вкладке, сообщения других пользователей, старую историю, занятое поле ввода и покупателя в игноре. Лимит — один ответ в минуту на чат. Нет фоновой работы при закрытом браузере.
- Для автоответа нужны распознанные чат, профиль покупателя и уже загруженные сообщения с числовыми ID. Если разметка не распознана, Helper не отправляет сообщения.
- Перед отправкой автоответ резервируется в локальной истории; две вкладки координируются через Web Locks. Если FunPay отклонит отправку, автоматического повтора не будет. Проверяйте появление ответа в чате: передача формы не доказывает доставку сервером.
- Изменения разметки FunPay могут потребовать обновления селекторов. Сообщения без явной ссылки на автора, в том числе некоторые сгруппированные, намеренно не обрабатываются.
- Метки общие для данного профиля браузера; разделения по аккаунтам продавца нет. Они не синхронизируются между устройствами. Удаление расширения удаляет его данные.

## Данные и разрешения

Расширение запрашивает только `storage` и запускает content script на `https://funpay.com/*`. Не использует аналитику, внешние библиотеки, cookies API, пароли или API-токены. Настройки, метки, заметки и история обработанных сообщений сохраняются в `chrome.storage.local`. У заметок нет доступа к выполнению HTML: пользовательский текст выводится через `textContent`.

## Разработка и проверка

Нужны Node.js 18+ и Python 3.10+. Устанавливать npm-пакеты не требуется.

```sh
cd /workspace/Funpay-Helper
npm test
npm run build
```

`npm test` запускает проверки идентификаторов, шаблонов, входных данных, перевода и условий автоответа. Сборка проверяет ссылки в манифесте и создаёт ZIP со всеми файлами расширения в корне.

Для браузерных проверок нужны Chromium и Python-пакет `websockets` (в подготовленной облачной среде уже есть):

```sh
python -m pip install -r tests/requirements.txt
npm run test:browser
```

По умолчанию тест подставляет production-скрипты и тестовый адаптер `chrome.storage` на перехваченную тестовую страницу. Ни запросов в реальный личный кабинет, ни отправки настоящих сообщений нет. Результат и снимки интерфейса записываются в `dist/`. Браузер запускается в отдельном временном профиле; `--no-sandbox` используется только тестовым процессом для работы в облачном контейнере.

На Chromium 137+ без запрета установки расширений можно отдельно проверить настоящую загрузку Manifest V3:

```sh
FPH_REAL_EXTENSION=1 npm run test:browser
```

Этот режим требует разрешённого DevTools-метода `Extensions.loadUnpacked`. В облачной среде он заблокирован политикой администратора. Политика не изменяется.

### Что проверено здесь

Модульные проверки и браузерные сценарии с тестовым хранилищем: тема, настройки, пользовательские метки, заметки, экранирование текста, игнор, шаблоны, перевод, подстановка ответов на отзывы, автоответ, защита истории и повторов между вкладками, сохранение черновика, видимость вкладки и смена чата.

**Не проверено:** установка расширения в браузер (административный запрет облачной среды), совместимость с реальным кабинетом и доставка сообщений на FunPay (сайт возвращает HTTP 403 из среды). Перед использованием автоотправки проверьте быстрый ответ в своём чате, а затем автоответ в контролируемом диалоге.

### Структура

- `extension/manifest.json` — описание и разрешения расширения.
- `extension/popup.*` — настройки и список покупателей.
- `extension/content.js` — панель, работа с формами, метки, игнор и автоответы.
- `extension/shared.js` — проверка данных, шаблоны и условия автоответов.
- `extension/theme.css` — оформление сайта.
- `tests/` — модульные проверки и браузерный стенд.
- `scripts/package.py` — упаковка без сторонних инструментов.

DOM-адаптер находится в `content.js`: заголовок `.chat-header`, сообщения `.chat-msg-item[data-id]`, автор `.chat-msg-author-link`, текст `.chat-msg-text`, форма `form.chat-form`; отзывы — `form.review-reply-form` / `.review-answer-form`; описание — `.lot-desc-text` и резервные селекторы. Эти селекторы проверены на стенде, не на актуальном аккаунте FunPay. Для изменения адаптера нужны обезличенные примеры HTML соответствующих элементов.
